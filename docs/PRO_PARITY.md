# Pro-feature parity

Verified against Splitwise’s official Pro feature list on 5 August 2026. FairShare is independently implemented and does not copy Splitwise code, branding, or visual assets.

| Official premium capability | FairShare status |
|---|---|
| Unlimited expenses | Included; no artificial daily limit |
| Transaction import | CSV bank-statement import included; live card feeds need a provider integration |
| Search | Included across descriptions, notes, and categories |
| Currency conversion | Included for individual entry conversion and whole-group conversion, preserving original values |
| Receipt scanning | Included through a configurable vision/OCR provider |
| Itemization | Included with person-by-person line-item assignment and extras distribution |
| Charts and graphs | Included for category and monthly spending |
| Default splits | Included for equal, percentage, and shares defaults |
| Ad-free experience | Included; there is no advertising layer |
| Early-access program | Not applicable to a self-hosted app; development branches/releases provide preview access |
